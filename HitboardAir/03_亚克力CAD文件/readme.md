### Hitboard Air - 壁纸自由流程

壁纸自由流程：

1.设计壁纸

用浏览器打开邮件中的，设计壁纸网页工具「01.Creator 工具」，设计你的壁纸，导出壁纸图片。
淘宝搜索店铺：E 彩冲印（拍 A4 尺寸 照片，根据店铺流程上传壁纸图片）

2.下单亚克力 

步骤 1：发文件
淘宝搜索店铺：德耀塑胶材料厂，跟客服拿一个接收文件的邮箱。把邮件中的 dwg 文件发给他。

步骤2：说需求
通过「02.布局示意图」，选取你需要的布局编号，比如A1。报给店铺客服：打印文件中的 A1，3mm，磨砂亚克力。

// 不同布局，差别在于加键
// A、B、C 字母编号影响右侧加键（食指左侧、大拇指右侧）
// 1、2、3 数字编号影响左侧加键（Shift 位置、W 位置）

3. 壁纸安装

【Hitboard Air 壁纸，喂饭级攻略】 https://www.bilibili.com/video/BV1UXoZBHE8U/?share_source=copy_web&vd_source=521fa607e5f082de7ab25fcafb9cb9a2

根据视频里的详细步骤，裁剪壁纸。
根据「03.亚克力盖板安装说明」，安装亚克力面板。// 记得撕掉亚克力保护膜。
